# Cover artwork

The approved cover appears in the founder's project message. Install the exact artwork here as `approved-cover.png` to build the cover-inclusive review edition. The repository checkout and attachment directory did not include an image file for this cover.

## Hardcover design proof

The Bennett’s Bone wrap supplied in chat is the visual and dimensional reference. This one-page proof uses its 14.471 × 10.417-inch outer dimensions to review the back, spine and front art placement together. The back-copy draft is editable in `back-cover.md`. Run `python scripts/cover_proof.py` from the book directory to rebuild the proof.

The front panel reserves space for the approved artwork visible in chat. The original high-resolution front image is still needed. For the print wrap, use a fresh KDP hardcover template for the 6 × 9-inch, 162-page book and selected paper and ink settings. Set the spine, hinge, wrap and barcode positions from that template.
