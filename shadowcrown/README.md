# Shadow Crown Universe site

Lives at **grooveville.org/shadowcrown/** inside the Grooveville Cloudflare Pages project. It keeps its own look; the Grooveville logo (top left) goes home, **‹ Back** goes back a step, and visitors arrive through the purple portal from the Shadow Crown Universe page on Grooveville.

## Starter notes
Lightweight GitHub-ready starter.

## Included
- Universe/home website, Book 1 hub and character roster
- Living World game shell with working tabs and map pins
- Charlotte map concept, Upendo House, Evolve Preparatory, basketball and VYBR8 discovery nodes
- Book 1 missions, daydream mechanic foundation, friends/co-op concept
- Compressed visual references to keep the ZIP small

## Character consistency
Use `/assets` as the current visual reference. Do not randomly redesign the Upendo family. Zeke is 10. Preserve age, skin tone, hair/family resemblance and Prince's appearance.

## Scope
Phase 1 is ONLY Book 1: `Zeke's Daydream`. Do not introduce Bermuda.

## Run
Deploys with the rest of the Grooveville repo on Cloudflare Pages. No build step. Links to `/logo.webp` and `/` assume it's served from grooveville.org.

## Status
This is a functional front-end starter, not a completed game engine. Navigation, game tabs, pins and responsive layout work. Real OSM tiles, accounts, saves, backend persistence, multiplayer and full game logic still need implementation.
